# Dalapa Botequim — cardápio digital

Projeto React + Vite mobile-first, pronto para publicar na Vercel.

## Rodar localmente
```bash
npm install
npm run dev
```

## Atualizar conteúdo
Edite `src/menu.js`. Os dados do cardápio estão separados da interface. Inclua somente textos e preços transcritos do material aprovado; a estrutura de um item está comentada no arquivo.

## Marca e imagens
Os arquivos de logo e dos seis prints não estavam disponíveis na pasta transferida. Quando forem adicionados, coloque a logo em `public/` e use-a no cabeçalho. O layout não depende de imagens e não inclui fotos ou produtos inventados.

## Publicar
Envie esta pasta a um repositório GitHub e importe-o na Vercel. Framework: **Vite**. Comando de build: `npm run build`; diretório de saída: `dist`.
